# RDIntelligence

Plataforma nacional de inteligencia con **datos abiertos** para República Dominicana.

Frontend: **React + Vite + Tailwind**. Sin backend en esta fase: consume APIs gratuitas (Open-Meteo, USGS, NHC, World Bank) y documenta heurísticas donde no hay feed público.

## Arranque

```bash
npm install
npm run dev
```

## Módulos

Riesgos · Clima · Inundaciones · Playas · Sargazo · Apagones · Tráfico · Incendios · Huracanes · Sismos · Dengue · Agrícola · Pesca · Turismo · Economía · Agua · Respiratorio

Ver detalle de fuentes en [`DOCS_FUENTES.md`](./DOCS_FUENTES.md) o en la ruta `/fuentes` de la app.
